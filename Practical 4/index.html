Tailwind CSS Classes Used

CSS Class Name Meaning (Why Used?) Description
bg-gradient-to-br Creates a diagonal background gradient Makes the page background attractive.
from-blue-100 Starting gradient color Begins the gradient with light blue.
via-cyan-100 Middle gradient color Creates a smooth transition between colors.
to-indigo-200 Ending gradient color Finishes the background with indigo.
flex Creates a Flexbox layout Aligns navigation items horizontally.
justify-between Adds space between items Places logo on the left and menu on the right.
items-center Centers items vertically Keeps navigation items aligned.
grid Creates a Grid layout Displays cards in rows and columns.
grid-cols-1 One grid column Used for mobile devices.
md:grid-cols-2 Two columns on medium screens Improves tablet layout.
lg:grid-cols-3 Three columns on large screens Displays three cards on desktops.
rounded-lg Rounds corners Makes cards and buttons look modern.
shadow-lg Adds a large shadow Highlights cards and buttons.
overflow-hidden Hides overflowing content Keeps images inside the card boundaries.
object-cover Fits image without distortion Ensures images fill their containers.
font-bold Makes text bold Highlights important text and buttons.
hover:scale-110 Enlarges element on hover Creates an interactive zoom effect.
hover:shadow-2xl Increases shadow on hover Makes the component stand out.
hover:-translate-y-1 Moves element upward Creates a lifting animation.
hover:rotate-2 Rotates element slightly Adds a playful hover effect.
hover:animate-pulse Applies pulse animation Draws attention to the button.
transition-all Animates all supported properties Provides smooth hover animations.
duration-500 Animation duration Controls how fast the animation completes.
max-w-6xl Sets maximum width Keeps content centered and readable.
mx-auto Automatic horizontal margin Centers the container horizontally.
min-h-screen Minimum screen height Ensures the background covers the full viewport.
