# Expense Tracker

A simple responsive expense tracker made using HTML, Tailwind CSS and JavaScript.

## How to run
1. Extract the project ZIP.
2. Open the `index.html` file in Chrome or any modern browser.
3. Add expenses using the form. Data is saved in browser local storage.

## Features
- Add expenses with name, amount and category
- Automatic total and expense count
- Delete individual expenses or clear all
- Responsive layout
- Browser local storage persistence

## Technologies
- HTML5
- Tailwind CSS (CDN)
- JavaScript
- Browser Local Storage
